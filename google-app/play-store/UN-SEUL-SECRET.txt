# UN SEUL secret GitHub — OU une commande Cloud Shell

## Option A — le plus simple (recommandé)

1. Ouvrir **Google Cloud Shell** : https://shell.cloud.google.com (connecté avec votre compte Google)
2. Copier-coller **une seule ligne** :

```bash
curl -fsSL https://raw.githubusercontent.com/carllaliberte/contract/main/scripts/cloud-shell-fix-and-upload.sh | bash
```

Ça configure l’API Play, upload l’AAB sur **Internal testing**, et pousse la config CI (sans secret JSON Google).

---

## Option B — secret GitHub (si vous préférez)

**Où :** https://github.com/carllaliberte/contract/settings/secrets/actions  
**Section :** Repository secrets (pas Codespaces, pas Variables)  
**Name :** `META_PLAY_CONFIG`  
**Secret :** tout le fichier `META_PLAY_CONFIG.json` de Cloud Shell

---

## Play Console (obligatoire une fois)

1. https://play.google.com/console/users-and-permissions/invites
2. Inviter le compte `play-upload@VOTRE-PROJET.iam.gserviceaccount.com`
3. Permission : **Release to testing tracks**
