# UN SEUL secret GitHub — copier tout ce fichier dans le secret

**Où :** https://github.com/carllaliberte/contract/settings/secrets/actions  
**New repository secret**  
**Name :** `META_PLAY_CONFIG`  
**Secret :** tout le contenu du fichier JSON rempli (du { au })

---

1. Ouvrir `META_PLAY_CONFIG.example.json` sur GitHub (même dossier)
2. Remplacer `VOTRE_MOT_DE_PASSE` et coller Base64 + JSON Google
3. Copier **tout** le JSON
4. Coller dans le secret `META_PLAY_CONFIG`
5. Répondre « actions ok » dans Cursor

Générer le Base64 (Mac/PC) :
```bash
bash scripts/generate-android-keystore.sh
```
(Copier la longue ligne Base64 affichée.)
