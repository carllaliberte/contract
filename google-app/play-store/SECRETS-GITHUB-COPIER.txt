META Dashboard — Fichier à remplir puis copier dans GitHub (Actions secrets)
================================================================================

OÙ COLLER SUR GITHUB (pas Codespaces) :
https://github.com/carllaliberte/contract/settings/secrets/actions

→ Onglet « Secrets » → section « Repository secrets »
→ « New repository secret » — 5 fois (un secret = un nom + une valeur)

Remplissez les lignes « VALEUR : » ci-dessous sur votre téléphone/PC,
puis copiez chaque VALEUR dans le champ Secret de GitHub (le Name est indiqué).

SECRET 4
Name GitHub : ANDROID_KEYSTORE_BASE64
VALEUR :
REMPLIR_BASE64_ICI

Comment obtenir le Base64 (sur un Mac/PC avec le dépôt) :
  cd contract
  ANDROID_KEYSTORE_PASSWORD='votre-mot-de-passe' ANDROID_KEY_PASSWORD='votre-mot-de-passe' \
    bash scripts/generate-android-keystore.sh
  Puis copier la longue ligne Base64 affichée par le script.

OU copier depuis le formulaire Cursor (champ ANDROID_KEYSTORE_BASE64) — une seule ligne, sans espaces.

================================================================================
SECRET 5
Name GitHub : GOOGLE_PLAY_SERVICE_ACCOUNT_JSON
VALEUR :
REMPLIR_JSON_ICI

Coller le fichier JSON Google Cloud entier, du { jusqu'au }, exemple :
{
  "type": "service_account",
  "project_id": "votre-projet",
  ...
}

OU copier depuis le formulaire Cursor (champ GOOGLE_PLAY_SERVICE_ACCOUNT_JSON).
