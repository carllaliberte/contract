Politique de confidentialité

Dernière mise à jour : 26 août 2026

Éditeur

Clapshot est publié par Carl Laliberté, Québec, Canada. Pour toute question : issues sur GitHub.

Données collectées

Clapshot collecte uniquement les données nécessaires au fonctionnement de l'application :

  • Identifiant Apple lors d'une connexion avec Apple (Sign in with Apple).
  • Nom et courriel si vous les fournissez via Apple (y compris Hide My Email).
  • Idées, scripts et contenus que vous créez dans l'app pour organiser votre pipeline vidéo (stockés localement sur votre appareil et, le cas échéant, synchronisés avec nos services).

En mode démo sans compte, les données restent sur votre appareil ; aucun compte n'est créé.

Utilisation des données

Ces données servent à vous authentifier, sauvegarder votre travail créatif et fournir les fonctionnalités de l'app (pipeline, scripts, quotas de génération). Nous ne vendons pas vos données et ne les utilisons pas pour de la publicité tierce.

Publicité et tiers

Clapshot n'affiche pas de publicité tierce. Nous ne vendons pas vos données personnelles. Les services Apple (connexion) sont soumis aux politiques d'Apple.

Suppression de compte et de données

Vous pouvez supprimer votre compte et les données locales associées depuis Réglages → Supprimer mon compte dans l'application (session Apple). Cette action efface les données stockées sur l'appareil et déconnecte votre session.

Pour une demande de suppression ou une question, ouvrez un ticket sur GitHub Support.

Sécurité

Les jetons de session sont stockés dans le trousseau iOS (Keychain) sur l'app natif. Les communications utilisent HTTPS. L'app n'utilise pas de chiffrement non exempté (export compliance : HTTPS uniquement).

English summary

Clapshot is published by Carl Laliberté (Québec, Canada). We collect your Apple user identifier, name and email when provided via Sign in with Apple, and the ideas and scripts you create to run the app. We do not show third-party ads or sell your data.
