Politique de confidentialité

CreatorFlow — Carl Laliberté
Dernière mise à jour : 25 août 2026 · English version

CreatorFlow est une application de pipeline de création de contenu (idées, scripts, production, publication). Cette politique décrit les données traitées dans l’app iOS, le web et l’API associée.

1. Données que nous collectons

  • Compte Apple (iOS) — identifiant Apple, nom et e-mail si vous acceptez de les partager lors de la connexion. Stockés de façon sécurisée (Keychain iOS) pour la session.
  • Contenu créateur — titres, descriptions et idées que vous saisissez pour générer des scripts. En mode démo, ces données restent sur l’appareil (stockage local).
  • Usage IA — compteurs mensuels de scripts courts/longs pour appliquer les quotas du forfait (Free ou Pro).
  • Achats intégrés — identifiants de transaction Apple (via StoreKit) pour valider l’abonnement Pro. Nous ne stockons pas vos informations de paiement.

2. Données que nous ne collectons pas

  • Pas de vente de données personnelles.
  • Pas de publicité ciblée ni de suivi publicitaire (NSPrivacyTracking = false).
  • Pas de clés API OpenAI ou secrets serveur dans l’application cliente.

3. Finalités

  • Authentification et gestion de session.
  • Génération de scripts IA et application des quotas.
  • Gestion des abonnements CreatorFlow Pro (validation des reçus Apple).
  • Support utilisateur.

4. Services tiers

  • Apple — Sign in with Apple, App Store, StoreKit.
  • Supabase — authentification et base de données (profils, usage).
  • OpenAI — génération de scripts (côté serveur uniquement).
  • GitHub Pages — hébergement de la démo web.

5. Conservation et sécurité

Les jetons de session sont stockés dans le Keychain iOS. Les communications utilisent HTTPS (App Transport Security). Vous pouvez vous déconnecter et supprimer les données locales depuis l’application.

6. Vos droits

Vous pouvez demander l’accès, la rectification ou la suppression de vos données en nous contactant. Pour les achats, utilisez aussi « Restaurer les achats » ou la gestion des abonnements iOS.

7. Enfants

CreatorFlow n’est pas destinée aux enfants de moins de 13 ans.
